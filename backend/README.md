# ModernTech API

## 📌 About the Project

ModernTech API is a backend REST API developed for **ModernTech Solutions**.

The API allows the application to manage employee information and communicate with a MySQL database. It was built using Node.js and Express.js, following a structured backend architecture with separate routes, controllers, and models.

---

## 🛠️ Technologies Used

- Node.js
- Express.js
- MySQL
- mysql2
- dotenv
- JavaScript (ES Modules)
- Git & GitHub
- Railway
